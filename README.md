
# Employee Management System

A simple **Employee Management System** built using **C** that manages employee records, payroll, and personal details.  
This system provides a command-line interface to manage and manipulate employee data, making it easier to maintain employee records efficiently.

---

## 📌 Project Description

The Employee Management System allows for adding, updating, and deleting employee records. It includes features like:

- **Employee Registration:** Add new employees with personal details.
- **Payroll Management:** Manage employee salaries.
- **Employee Deletion:** Remove employee records as needed.

The system uses file handling to store employee data and allows for CRUD operations (Create, Read, Update, Delete).

---

## 🧑‍💻 Features

- **Add Employee:** Register a new employee with essential details.
- **View Employee:** Search and view employee information.
- **Update Employee:** Modify existing employee details.
- **Delete Employee:** Remove an employee's record from the system.
- **Display All Employees:** List all employee details stored in the system.

---

## 💻 Technologies Used

- **Programming Language:** C
- **File Handling:** For storing employee records
- **Platform:** Linux / Windows

---

## 🚀 How to Run

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/IIUday/Employee-Management-System.git
   cd Employee-Management-System
   ```

2. **Compile the Code:**
   ```bash
   gcc employee_management_system.c -o employee_management
   ```

3. **Run the Program:**
   ```bash
   ./employee_management
   ```
